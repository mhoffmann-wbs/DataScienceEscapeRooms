# Room flows

One page per room with a Mermaid flowchart of every station, clue, data file and the final lock, with arrows labelled by the knowledge a team has to carry between them, and a short analysis (phases, chains, where things stand, weak clues). Written with the `room-flow` skill (`.claude/skills/room-flow/`); unlike the walkthroughs they are hand-maintained, so update a room's page when its puzzles, clues, reveals or locks change.
